The First Time you met Haskell

2026-10-24
  1. 笛卡尔积 是两个集合组成的有序数对 X×Y={(x,y)∣x∈X, y∈Y}

∀ (x, y) ∈ f, ∀ (u, v) ∈ f, x = u => y == v 唯一性

  1. 在 Haskell 中，“类型” 和 “集合” 是同义词

  2. g * f == g after f 右往左

  3. 函数可以建模 “变换” 和 “因果关系” 信息处理问题 对信息的变换

def not : 𝔹 -> 𝔹 = [b] match b { true => flse, flse => true, }

  1. [b] 是 函数参数绑定，也就是 lambda 抽象 lambda 抽象 是 λ 演算中用来定义匿名函数的基本语法形式

    match 是 模式匹配表达式，类似 case / switch，但用于函数式语言里的代数数据类型 表达式可以产生一个值

    模式子值： 实际子值 一个实际值拆开内部的部分 Some(3) 是实际值，3是实际子值

    因为模式匹配不是匹配代码文本，而是匹配运行时真正的值

def ℕ : TYPE = { ctor zero : Self ctor succ : Self -> Self } 6. 本质 皮阿诺公理 定义自然数就需要 zero 和 后继（succ） 这个公理也成为 数学归纳法的基础（归纳公理）

满足这两个性质的集合 就是 N自然数集合

self什么意思：定义内部用 Self 来指代当前正在定义的类型

所以在这段语言中 self 就是N

  1. ctor 构造子 constructor
    某个类型的值不是随便来的，而是由这个类型规定好的几种“造法”造出来的。每一种造法，就叫一个构造子

    构造子 规定 一个类型的值的 生成形式 而这个 类型叫做 type
    ctor zero succ 中的zero succ是构造子

    ctor 定义一个结构子
